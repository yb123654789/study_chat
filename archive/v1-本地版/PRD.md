# 学习bot · 需求定稿 v1

> 一句话：**一个「聊天就能用」的本地学习流程工具——你嘴上说，它负责记录、排程、追问。**

上一轮你的五个痛点是「全都想要」，所以这里不按功能堆，而是按**一条主循环**收敛：
**捕获 → 排程 → 主动回忆 → 反馈**。五个痛点分别挂在这条循环的四个环节上。

---

## 一、定下来的六个决策

| 维度 | 定稿 | 理由 |
|---|---|---|
| 要解决什么 | 五个痛点全要，但只做**一条闭环**，不做五个独立功能 | 功能一多就没人用；闭环跑起来，五件事自然都被覆盖 |
| 学习范围 | 通用、多科目（英语/数学/编程/考证…） | 你的内容会变，工具不该跟着重做 |
| 产品形态 | **对话式**：入口就是现在这个对话窗口 | 零配置、零 API key、数据全在你本地 |
| 数据 | 单个 `data/study.json`，纯本地 | 好备份、可迁移、随时能看 |
| 提醒方式 | **被动**：你打开对话时，它先告诉你今天该干什么 | 你不定时间，主动推送只会变成噪音 |
| 学习节奏 | 不设每日配额，**到期驱动 + 5 分钟起步** | 时间不固定的人，配额只会带来负罪感 |

## 二、明确不做（v1 边界）

- ❌ 独立 App / 账号 / 云同步 / 多设备
- ❌ 强制锁机、惩罚式打卡（拖延用「把任务缩小」解决，不靠自责）
- ❌ AI 自动总结你的资料（先把输入→输出跑通，这是 v2 的事）
- ❌ 复杂甘特图、课程表编排

## 三、核心循环

```
你学完一个东西
   ↓ 一句话告诉我  →  .\study learn "..."        ① 捕获
系统排好下次复习  →  次日/3 天后/7 天后…        ② 排程
你打开对话        →  .\study today  告诉你该复习 ③ 主动回忆
你口述答案        →  我判分并丢给排程            ④ 反馈
```

关键设计：**复习不是打勾，是口述。** 答不出来就不给「记得」——评分失真比心情重要，
因为整个复习节奏都建立在评分上。

## 四、五个痛点 → 落在哪

| 你的痛点 | v1 怎么解 |
|---|---|
| 学了记不住 | 简化版 SM-2 间隔：1 → 3 → 7 → 16 → 35 天；忘了就回到 1 天 |
| 不知道该学什么 | `today` 按「逾期 → 今天到期 → 很久没碰」排序，一次最多给 3 条 |
| 专注不下来 / 拖延 | 默认 25 分钟一块，一条命令开记；不想学时只给「5 分钟 + 一个动作」 |
| 资料太散 | 统一成「条目 + 随手记」两种，全部可 `search` |
| 不知道自己学得怎样 | `stats` 看数字，`dashboard.html` 看趋势（连续天数、5 周热力图、科目分布、通过率、反复忘的条目） |

## 五、排程规则（写死，不靠感觉）

- 评分四档：`again` 没想起来 / `hard` 勉强 / `good` 记得 / `easy` 很简单
- `again` → 间隔重置 1 天，难度 +0.2（最低 1.3）
- `hard` → 间隔 ×1.2；`good` → ×难度系数；`easy` → ×1.3 倍难度系数
- 首次 1 天，第二次 3 天，上限 180 天
- 间隔 ≥ 60 天自动标为「长期记忆」（仍会偶尔回顾）

## 六、验收标准

1. 说「我学了 XXX」，30 秒内得到下次复习日期，且不用打开任何网页
2. 打开对话，5 行内知道今天该复习什么
3. 复习时我说不出来，系统不会给我排到 7 天后
4. 手机上也能看：`dashboard.html` 双击即开，不联网、无外部依赖
5. 数据只有一个文件，复制走就能换电脑

## 七、怎么用（就这三句）

```
「我学完了 拉格朗日中值定理，数学，25 分钟」   → 记录 + 排明天复习
「今天学什么」                                  → 给你今天的清单
「开始复习」                                    → 一条一条考你，答完自动排下次
```

命令层（你也可以直接敲）：

| 命令 | 作用 |
|---|---|
| `.\study today` | 今日清单 + 连续天数 |
| `.\study learn "标题" -s 科目 -m 25` | 学完记录，自动排复习 |
| `.\study review t003 -g good` | 记录一次复习结果 |
| `.\study note "一句话"` | 随手记 |
| `.\study search 关键词` | 找条目和随手记 |
| `.\study stats -d 7` | 近 7 天统计 |
| `.\study dashboard` | 重新生成看板 |
| `.\study reset --yes` | 清空全部数据（会先问一次） |

# 学习bot 桌面版（app/）

> **2026-10-28（手机版 P0）**：Telegram 已摘——不跑 bot、不推送、不用代理；
> 「机器人」页换成了「待确认」页；模型 key 只在「设置」里填（不再读 `.env`）。
> 下面提到 Telegram / 07:00 推送 / 机器人页的段落是旧流程，留到手机版 P8 后统一清。

电脑上开这一个窗口：**带练聊天、资料入库、排计划、看目标、管题库、待确认** 全在里面。
手机端换成 Android App（手机版 P1 起）——白天学、被提问、答小测。没有网页。

---

## 怎么开

双击项目根目录的 **`学习bot.cmd`**（不会弹黑框）。

或手动：

```powershell
py -X utf8 app\main.py          # 带控制台，方便看报错
py -X utf8 app\main.py plan     # 直接打开某一页（调试用）
```

依赖：Windows + Python 3.10 以上（只用标准库，不用 pip 装任何东西）。

## 连服务器（瘦客户端，2026-10 起）

后端跑在 VPS 上（宿舍断电也不影响）。在 `data/desktop.json` 里写：

```json
{"server": "http://你的服务器:8787", "token": "服务器 data/server.json 里的那串"}
```

- **有这个文件** → 桌面只显示和操作；bot、定时推送、模型调用、数据库都在服务器上跑。
- **没有这个文件** → 退回本地模式（数据在本机 `data/studybot.db`），没网时调试用。

> ⚠️ **只能在一处写数据**：切到服务器后，别再拿另一台机器/另一个窗口写本地库，否则两边会对不上。
> 服务器怎么架：见 `server/README.md`（systemd、备份、HTTPS/Tailscale）。

## 多门课（2026-10-27 起）

一门课一个「课程」记录，各排各的计划：

- **顶栏下拉**切课程：「学习 / 计划 / 目标 / 题库 / 资料」都只显示这一门课；「总览」显示全部课程的
  今日任务（按课程分块），脚本推送也是一条消息里按课程分组。
- **设置页**「这门课」：改课程名、考核日、周末多学 %、每日上限分钟（0 = 不限）。
  **每天学多少不手填**：排程按「没学完的分钟 ÷ 剩余天数」自动算，落后越久每天越长；
  周末只是按系数加权（默认 130%），不再写死「工作日 X 分钟 / 周末 Y 分钟」。
- **设置页**「加一门课」：id 用英文短名（`math` / `os`），本科的考核日自己填。建好后：
  1. 目标放 `data/goals_<id>.json`（格式同 `data/goals.json`），在「目标」页点「导入这门课的 goals」。
     id 和数据结构撞了会自动改成 `<id>-g01` 这种，不会覆盖原来那门课。
  2. 资料放 `materials/<id>/inbox/`，在「资料」页点「扫描 inbox」；或者整批目录跑
     `py tools/extract.py --course <id>`（抽到 `extracted/<id>/`，检索只在这门课里找）。
  3. 「计划」页点「重新排计划」（只排这一门）。
- **落后按课各算各的**：某门课欠了卡，只重排那一门，别的课不动；推送里会写明是哪门课落后几天、
  牺牲了哪些复习卡。
- 数据结构是第一门课（id `ds`），数据原样保留。

## 第一次用（5 分钟）

1. **填 Bot Token**：在 Telegram 里找 `@BotFather` → `/newbot` → 拿 token → 粘到「机器人」页 → 保存。
2. **测试连接**：点「测试连接」，能看到 `@你的bot` 就通了。
   - 如果报「连不上 Telegram」，把代理填上（Clash 默认 `http://127.0.0.1:7890`），再测。
3. **启动 bot**：点「启动 bot」，左下角变成绿色的运行中。
4. **手机上绑定**：给 bot 发一句 `/start`。电脑上「当前状态」会显示 chat_id，
   之后任何人都不能被这个 bot 服务（单人白名单）。
5. **确认模型能用**：「设置」页填 API Key（或用根目录 `.env` 的 `DEEPSEEK_API_KEY`），
   然后在手机上选一张卡问一句，能答就通了。

## 电脑上怎么用（「学习」页）

左边是今天的卡（张数不固定，按当天分钟数摊；落后时一天会多几张），点一张进右边的对话：

- 直接问（「这节考什么」「为什么先定 ADT」），回答会引用资料原文，底下标出处
- 说「出题」或按右下角「小测 3 题」→ 弹窗里 3 题，2 对算完成
- 对话和 Telegram 端**是同一段**：手机上聊到一半，电脑打开接着聊
- 状态条（今天几/几张、已学多少分钟、落后几天）由代码算，模型只能引用，不能改
- 模型想「开始小测 / 跳过这张卡 / 看计划」只能调工具，代码决定做不做

## 手机上怎么用

| 你说 | 它做什么 |
|---|---|
| `/start` `/today` | 今天的任务（张数按当天分钟数定），每张一个按钮 |
| 点某张卡 | 进入聊天学习：直接问，它按你的资料回答并给出处 |
| 「出题」 | 3 道题：2 选择（按钮点）+ 1 简答（直接回） |
| 答完 | 3 题对 2 就记为完成；没过就留到明天，可换套题再考（24h 内最多换 2 次） |
| 「测测我」 | 走工具调用开小测，不让模型自己编题 |
| `/plan` `/stats` | 计划概览 / 进度 |
| `/skip` | 跳过当前这张卡 |

推送：每天 **07:00** 推今日任务；**21:30** 如果还有没做完的，再催一次。
到点后 4 小时（早间）/ 2 小时（晚间）内开机才补推，再晚就记一条日志、当天不补——半夜收早间推送不是提醒。
**软件必须开着**（电脑睡眠不影响已触发的推送，但关机就不推了）。

## 资料：一级 → 二级 → 三级

**一级（原始资料）**：把 PDF/PPTX/DOCX/MD/TXT、图片、音视频丢进 `materials/inbox/`
（其他课 `materials/<课程id>/inbox/`），在「资料」页点 **「处理 inbox（抽文本→归档）」**：
抽出来的文本写进 `extracted/<课>/inbox/`，**原件挪进 `回收站/<课>/`**（不是硬删，能翻回来），
`原始资料清单.json` 记一份台账（名字/大小/哈希/字数/去向）。

- 图片要 OCR → 装 [tesseract](https://github.com/UB-Mannheim/tesseract/wiki)（中文包 `chi_sim.traineddata` 放工具目录的 `tessdata\`）
- 音视频要转写 → 装 ffmpeg + [whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases)，再下一个 ggml 模型
  （中文推荐 `ggml-large-v3-turbo.bin`，1.6GB）
- **不用自己找链接**：设置页「外部工具」有四个下载按钮，还有「检查工具」和「打开工具文件夹」
- 工具统一放 `%LOCALAPPDATA%\studybot-tools`，**路径里别带中文**（whisper.cpp 打不开中文路径）
- 没装也不影响文本类资料——图片/视频会留在 inbox 等工具装好
- 处理是**并行**的（文本/图片最多 4 路，音视频串行），表里每份文件一行实时状态，顶部有总进度和「取消」
- **断了能续**：每份处理完立刻记进台账，中途关软件/断电，下次只处理没做完的；同一份再放进来会自动跳过

**二级（课程内容 / 知识库）**：`知识库/<课>/<章>/<id>-<标题>.md`，每个目标一个文件，
正文是从原文里检索到的摘录，前面的 front matter 带版本号和标签；`_索引.md` 是全课目录。
它**只由程序生成**（「拆目标 + 建知识库」或「重建知识库」），内容变了才升版本，旧版留在 `知识库/.history/`。

**三级（日常数据）**：题库、答题记录、聊天、今天的计划——在库里随情况改，随便动。

> 知识树：二级文件里已经留了 `tags` 字段，等课多了再做跨课程的概念树，现在不建。

## 打包成 exe（目录版，2026-10-27 晚改）

```powershell
py -m pip install pyinstaller        # 只有打包需要，运行时不依赖
双击 学习bot-打包.cmd                 # 或 py -m PyInstaller --noconfirm --clean build\学习bot-onedir.spec
```

产物：`dist\学习bot-app\`（`学习bot.exe` + `_internal\`，共约 30MB）。双击 `学习bot.exe` 即开，不需要装 Python；
**分发时整个文件夹一起拷/压 zip**，只拷 exe 是跑不起来的。

**必须拷到工作区外面再运行**：exe 留在 DSH 工作区里跑会被工作区限制，只能写工作区内，于是
`%TEMP%`、`%LOCALAPPDATA%`、`文档` 全写不进去（报 `Could not create temporary directory!`、
`Failed to extract VCRUNTIME140.dll: ... Permission denied`、`PermissionError: location.json`、
`unable to open database file`——全都不是程序逻辑出错）。
`学习bot-打包.cmd` 打完会自动拷到 `%USERPROFILE%\学习bot-app`，以后双击那份即可。

- 打包脚本会自动重试一次：Python 3.14 + PyInstaller 6.22 偶尔在分析阶段崩（`TypeError: 'int' object is not an iterator`）。
- 打包固定用 Python **3.14**（`%LOCALAPPDATA%\Programs\Python\Python314\python.exe`），别用 `py`——这台机器上 `py` 现在指向 3.15，里面没装 PyInstaller。

- **数据不打包**：第一次运行会问「数据放哪」，默认 `我的文档\学习bot`；也可以直接选已有的数据文件夹
  （里面有 `studybot.db` 就接着用）。选过的位置记在 `%LOCALAPPDATA%\学习bot\location.json`。
- 脚本/调试时可以覆盖：`set STUDYBOT_HOME=D:\学习bot数据`。
- 出错了会写 `crash.log` 到数据目录，并弹窗提示。

## 数据在哪（有规则）

所有数据只在**一个数据目录**里，程序目录（或 exe）可以随时换：

| 位置 | 内容 |
|---|---|
| `<数据目录>\studybot.db` | 唯一数据库：课程、目标、任务、题库、答题、聊天、设置、日志 |
| `<数据目录>\goals.json` / `goals_<课程>.json` | 目标来源（「目标」页导入） |
| `<数据目录>\materials\`（`materials\<课程>\`） | 原始资料，**程序只读**，只在 inbox 下建目录 |
| `<数据目录>\extracted\` | 抽出来的文本，检索用 |
| `<数据目录>\backups\` | 每天第一次启动自动备份，保留最近 20 份 |
| `<数据目录>\exports\` | 「导出 JSON」，给人看的全量快照（不含 key/token） |
| `<数据目录>\.env` | `DEEPSEEK_API_KEY`（可选，也可以在「设置」里填） |
| `<数据目录>\desktop.json` | 瘦客户端连服务器的地址+token（可选） |

数据库结构带版本号（`schema_version`），升级程序会自动迁移；迁移前的库在 `backups/` 里能找到。

> 开发模式（直接 `py app\main.py`）默认还用项目里的 `data\`，资料和 `extracted\` 仍在项目根，
> 免得动到已有文件；打包后的应用统一收进数据目录。

## 代码结构

| 文件 | 作用 |
|---|---|
| `main.py` | 入口：建库、首次排计划、开窗口、调页面 |
| `ui.py` | 全部界面（Tkinter，10 页，含「学习」带练 + 小测弹窗） |
| `db.py` | SQLite 表结构与读写（含 `conversations` / `messages`） |
| `chat.py` | 带练引擎：会话落库、状态条、检索、工具调用（两端共用） |
| `engine.py` | 排程（复用 `tools/planner.py`）、检索、出题、判分、入库 |
| `llm.py` | DeepSeek 调用（含 function calling）+ 提示词 + 降级（关键词判） |
| `bot.py` | Telegram 报文、状态机（学→出题→判分→记账） |
| `service.py` | 长轮询线程 + 07:00/21:30 定时推送线程 |
| `paths.py` | **数据目录规则**：代码只读，库/资料/备份/导出全在一个目录；第一次运行选目录 |

## 已知限制

- **Telegram 需要代理**：电脑和手机都要能连上，否则 bot 完全不可用。
- **模型挂了就降级**：出题退化成验收点简答，批改退化成关键词命中——不假装通过，但也不保证严格。
- **电脑关机 = 不推送**。要 100% 准点，得把 bot 搬到常开的小机器上（还没做）。
- **资料新增不会自动变成新目标**（增量重拆未做）。
- **聊天记录只增不删**：一个任务一条会话，没有自动清理；嫌长可以在「学习」页点「清空对话」。
- **课程 id 别和资料目录重名**（`笔记`/`书`/`PPT`/`试卷`/`大作业`），会被拒；新课程资料按
  `extracted/<课程id>/` 归类，检索才分得清。
- 消息里的公式、表格排版很差；代码题只能发文字。

# 预览版（本地服务 + 真模型）

```powershell
python tools/serve_preview.py --port 8787
```

然后打开 <http://127.0.0.1:8787/>。服务默认只绑 `127.0.0.1`（不要绑 0.0.0.0：`/api/chat` 会花你的 key）。

聊天走 `/api/chat` 代理，key 从项目根目录 `.env` 的 `DEEPSEEK_API_KEY` 读（已加进 `.gitignore`，永不下发前端）。没有 key 时自动退回本地模拟，界面右下角会显示当前是哪种。

## 数据从哪来

| 文件 | 来源 | 真假 |
|---|---|---|
| `data/plan.json` | `tools/export_web.py` 调 `planner.py` 导出的真实排程（73 天 / 59 目标） | 真 |
| `data/reading.json` | `tools/build_reading.py` 从 `extracted/` 关键词检索的原文段落（带文件+页码） | 真（检索，不是模型总结） |
| `data/quiz.json` | 手写示例题，只覆盖 g01–g06 | 假（正式版由模型生成） |

## 真的部分

- 今天的任务是真实排程结果：g01（35 分）+ g02（50 分），周六容量 153 分钟
- 点任务进**聊天窗口**，说话、点「例子」「考什么」、说「出题」都会走通
- 配了 key 时聊天是**真模型**（deepseek-flash），一轮约 3–4 秒、¥0.01
- 每轮会按你的问题实时检索 992 个资料块，命中的 3 段连出处塞进上下文，回答下面显示引用来源
- 通过判定按规则：3 题对 ≥2 才算过，否则标记「明天补」
- 容量档位 1/2/3 小时；排不下会提示顺延
- 进度和聊天记录存 localStorage，刷新不丢

## 假的部分

- **没有 key 时聊天回复是本地模拟的**：只能从检索到的资料片段里拼回答，会把原话贴给你，但不会真的讲解、不会追问你的思路
- 题库只有 6 个目标，其余卡片点开会提示「这套题还没生成」
- 简答用关键词命中判定（正式版调模型按要点批改）
- 「再考一次」用的是同一套题（正式版会重出，24h 内最多 2 次）
- 没有数据库、没有推送、没有邮件、没有登录

## 已知限制

`http://` 不是安全上下文，Service Worker 不生效，**「添加到主屏幕」装不出全屏窗口**——要等部署到 Cloudflare Pages（https）。现在手机上只是在浏览器里看效果。
